Google Drive Setup Guide
1. console.cloud.google.com → Create project "iDeepin"
2. Enable Google Drive API + Google Calendar API
3. Create OAuth 2.0 credentials → download client_secret.json
4. First run: flow = InstalledAppFlow.from_client_secrets_file('client_secret.json', SCOPES)
5. Create folder /iDeepin/ in Drive → subfolders: data/, reminders/, uploads/, logs/, exports/
6. Key files: portfolio_memory.json (append-only) · stock_scores.json · etf_analysis.json
7. Read/write via: service.files().get_media(fileId=id) and service.files().update()
Google Calendar Integration — Strategy Reminders
Uses same OAuth credentials as Drive setup above.
Create reminder: service.events().insert(calendarId='primary', body=event)
Color coding: colorId 11=Red (SELL alerts) · 10=Green (BUY signals) · 5=Yellow (WATCH) · 9=Blue (Earnings)
Conditional strategy: Store in event description — "IF NVDA drops 10% post-earnings THEN buy AMD at $420"
Delete reminder: service.events().delete(calendarId='primary', eventId=event_id)
List iDeepin reminders: events().list(calendarId='primary', q='iDeepin')
Reminder timing: popup 30 min before · email 60 min before · both set automatically
☁ Hosting Guide — GitHub Pages (Free · No install · Permanent URL)
One-time setup — 5 minutes in Chrome:
1 · Go to github.com → Sign Up (email + password, no card needed)
2 · Click + top-right → New repository → name it ideepin → Public → Create repository
3 · On the next page click "uploading an existing file"
4 · Drag your ideepin_v1.html file into the browser (rename it index.html first)
5 · Scroll down → click Commit changes
6 · Click Settings tab → left sidebar → Pages → Source: main → Save
7 · Wait 2 minutes → open: https://YOUR-USERNAME.github.io/ideepin

Updating when new version is ready: Go to repo → click index.html → pencil edit icon → paste new content → Commit. 30 seconds.

Step 4: Schedule the 9:15 AM CST cron job on your server
